# Weekly Notes

One retro per week. Solo-founder sustainability + scope-creep early warning.
Source pattern: `docs/05-development/build-sequence.md` → "Tracking Progress".

Naming: `YYYY-MM-DD.md` (date of the Saturday review).

## Template
```markdown
# Week of YYYY-MM-DD

## Metrics
- Hours worked:
- Tasks completed:
- Tasks added (scope-growth signal):
- Tech debt accumulated:
- Bugs fixed:
- Mood / energy (1-10):

## What shipped

## What's blocked

## Next week's focus

## Notes
```

> If mood/energy drops below 5 for 2+ weeks, take a real break.
> The live snapshot of where the project is lives in `/STATUS.md`.
