## What went well
- **The review gates repeatedly caught green-tests-but-broken-app bugs — the entire point of running them.**
  Across Slice 1–2: the whole-branch review found the app couldn't reach the network on a real emulator
  (tests mock the channel); `/code-review` found the `/auth` request contract was wrong (couldn't log in) and,
  in Slice 2, that you couldn't clear an address field in edit mode and that the iOS Maps key only worked from
  Xcode. Five Slice-2 fix-loops each caught a real defect (2 weak contract tests, 2 silent error-swallows, 1
  blank edit form) that passing tests had hidden. None of these would have been caught by the test suite alone.
- **SDD held up over an 11-task slice.** Fresh implementer per task + spec/quality review + ledger survived a
  watchdog stall (recovered the uncommitted work), the org spend-limit 429s (fell back to inline execution),
  and compaction — the ledger was the recovery map every time.
- **The backbone compounded.** Slice 2's two feature modules reused Slice 1's Result/repository/interceptor/
  theme with zero new primitives; the design system from #24 flowed into every Slice-2 screen for free.

## What hurt / to watch
- **The mocks-agree-with-themselves failure mode is now the dominant bug source.** Every serious bug this arc
  was a green suite hiding a broken integration (real network, real Zod schema, real device, real Maps SDK).
  The standing lesson (memory: mocked-transport-false-confidence) needs teeth: **add a real backend
  contract-smoke test** before Slice 3 hits more endpoints, and treat "can this invariant be covered by a
  test?" as a gate-design question (the Maps `MAPS_ENABLED`-without-key crash slipped because dart-defines
  can't be set in tests — the fix collapsed two conditions into one testable one).
- **The retro ritual keeps slipping AND a retro got lost in a squash.** The 2026-09-05 retro was committed on
  a branch and never reached main. Two lessons: (1) the weekly ritual still has no Stop-hook enforcement (the
  CLAUDE.md-named fix) and lapsed the whole customer-app arc; (2) docs committed late on a feature branch can
  be dropped by a squash-merge that snapshotted an earlier push — the same mechanism that left the maps crash
  fix out of #25 until #26 caught it. **Push doc/fix commits before opening the PR, or verify main after merge.**
- **iOS is a real second surface now.** Multiple iOS-only issues this arc (CocoaPods not installed via Xcode's
  ▶, ATS cleartext scoping, the Maps key build-setting-vs-env, the SIGABRT) — none buildable in the agent
  environment (no Xcode), so each needed a founder device round-trip. Budget for that on every maps/native slice.
