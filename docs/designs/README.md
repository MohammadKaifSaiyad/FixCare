# designs — Brainstorming Specs

Design documents produced by the Superpowers **brainstorming** skill, one per
feature. The output of refining a rough idea into an approved design before any
planning or code.

**This is where brainstorming writes specs** (the project convention — see
CLAUDE.md). Naming: `YYYY-MM-DD-<feature>-design.md`.

Flow: `designs/` (this folder) → `plans/` (implementation plan) → code.
