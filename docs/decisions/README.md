# decisions — Lightweight Decisions

Small decisions that don't warrant a full ADR but are worth recording so you
don't re-litigate them. Things like "why OneSignal over raw FCM", "why Bruno
over Postman".

Naming: `<short-slug>.md` (e.g. `why-onesignal-over-fcm.md`).

**ADR vs decision:** if it's expensive to reverse or structural, write an
[ADR](../adrs/README.md). If it's a small, local call, write it here.
