# plans — Implementation Plans

Implementation plans produced by the Superpowers **writing-plans** skill — an
approved design broken into small (2-5 min) tasks with exact file paths, code,
and verification steps.

Naming: `YYYY-MM-DD-<feature>.md`.

Flow: `designs/` (approved design) → `plans/` (this folder) → code via
`executing-plans` / `subagent-driven-development`.
